## AAA parity closure plan (practical path to A-tier)

### Phase 1 — Grading hygiene hardening (mandatory before algorithm changes)

1. Require every newly-added callable to have a `GRADES_VERIFIED.csv` row in the same PR.
2. Add CI gate: fail if `MISSING + AMBIGUOUS_NAME_MATCH > 0` for touched files.
3. Split class grades from callable grades into separate sheets/tabs so metrics are non-ambiguous.

### Phase 2 — Highest-impact algorithmic uplift clusters

Prioritize files with highest non-exact counts and direct player-facing output impact:

- `environment_scatter.py`, `environment.py`:
  - Blue-noise / ecological spacing constraints.
  - Biome- and slope-aware species assemblage balancing.
  - Deterministic seed reproducibility checks at profile level.
- `_terrain_noise.py`, `terrain_features.py`:
  - Multi-frequency domain warping + erosion-coupled noise blending.
  - Explicit geomorph class controls (valley/ridge profile families).
- `road_network.py`, `_water_network.py`:
  - Cost field realism (grade limits, curvature penalties, hydrology conflict resolution).
  - Bridge/ford/culvert decision modeling with budget-aware variants.
- `terrain_caves.py`, `terrain_cliffs.py`:
  - Structural plausibility scoring and fail-fast validators.
  - Readability + gameplay-space metrics wired into pass outputs.

### Phase 3 — Grade reliability guardrails

1. Require evidence links/tests per grade change (prevent "grade drift").
2. Add reproducible benchmark snapshots for runtime-heavy passes.
3. Add visual-diff baselines for key terrain archetypes before/after upgrades.
