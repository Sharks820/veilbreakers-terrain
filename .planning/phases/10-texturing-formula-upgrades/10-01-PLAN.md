<objective>
Implement structural terrain-type labeling pass (Fix 10.10 / REQ-P10-001).

This is the ARCHITECTURAL foundation for all Phase 10 texturing work. The current system
classifies materials analytically after the fact (slope threshold → rock). The correct AAA
approach (Rune Skovbo Johansen) is: feature generators stamp authored labels during
generation; the materials pass reads those labels as authoritative overrides and falls back
to analytical classification only for unlabeled cells.

Purpose: Every subsequent Phase 10 fix (normal rock mask, Brucks blend, snow mask) operates
on top of a labeled stack. Landing the architecture first prevents rework.

Output:
- `pass_compute_terrain_labels` in terrain_pipeline.py (registered before structural_masks)
- Label-override block in terrain_materials_v2.compute_slope_material_weights
- Test suite verifying override priority and fallback
</objective>

After the existing per-channel loop that builds `weights`, apply label overrides:

```python
if has_labels:
    # Map label channel → splatmap layer index.
    # Only assign if the target channel_id exists in the rule set.
    _label_channel_map = {
        "rock_label":   ("cliff",),     # rock structural label → cliff material
        "gravel_label": ("scree",),     # gravel structural label → scree material
        "water_label":  ("wet_rock",),  # water structural label → wet_rock material
        "cliff_label":  ("cliff",),     # cliff structural label → cliff material
    }
    label_arrays = {
        "rock_label":   rock_label,
        "gravel_label": gravel_label,
        "water_label":  water_label,
        "cliff_label":  cliff_label,
    }
    for label_key, target_ids in _label_channel_map.items():
        lbl = label_arrays[label_key]
        if lbl is None:
            continue
        lbl = np.asarray(lbl, dtype=np.float32)
        labeled = lbl > 0.5  # boolean mask of labeled cells
        if not labeled.any():
            continue
        for target_id in target_ids:
            try:
                tidx = rules.index_of(target_id)
            except KeyError:
                continue
            # For labeled cells: zero all layers, then set the target layer to 1.0
            weights[labeled, :] = 0.0
            weights[labeled, tidx] = 1.0
```

Do NOT re-normalize labeled cells (they are already sum=1.0 after the override).
Run the existing normalization step only on unlabeled cells:

```python
total = weights.sum(axis=2)
default_idx = rules.index_of(rules.default_channel_id)
# Only apply fallback and normalization to cells that were NOT overridden by labels
if has_labels:
    all_labeled = np.zeros((H, W), dtype=bool)
    for label_key, lbl in label_arrays.items():
        if lbl is not None:
            all_labeled |= (np.asarray(lbl, dtype=np.float32) > 0.5)
    unlabeled = ~all_labeled
    empty = (total <= 1e-9) & unlabeled
else:
    empty = total <= 1e-9
    unlabeled = np.ones((H, W), dtype=bool)

if empty.any():
    weights[empty, default_idx] = 1.0
    total = weights.sum(axis=2)

# Normalize unlabeled cells only
norm_denom = np.where(unlabeled, total, 1.0)  # labeled cells already sum=1
weights[unlabeled] = (weights[unlabeled] / norm_denom[unlabeled, None])
```
